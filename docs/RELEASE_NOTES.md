The initial public-source collection for the reproducibility study of arXiv:2610.31458.

The ZIP contains 953 files, including 30 papers, 561 official figure/table PDFs, a pinned public CMS analyst repository, numerical histogram exports, CERN data inventories, auxiliary inputs and four complete event/simulation sample files.

Every inventoried file was checked against the preserved SHA-256 manifest before packaging. The four event files additionally match the original CERN Adler-32 checksums. The ZIP's own SHA-256 is attached separately; its packaging timestamp may differ from the originally delivered ZIP, while inventoried file contents are unchanged.

This is an access and acquisition snapshot, not a completed reproduction. Official HEPData exports and final likelihood inputs remain outstanding; the 310 GB CMS and 49 TB ATLAS full datasets are not included. Read the attached report and repository README for coverage and provenance limits.
